# Inferencia estadística

Proyecto seleccionado como muestra principal del portafolio.

## Objetivo

Aplicar estadística descriptiva e inferencial sobre una muestra simulada de 200 estudiantes, incorporando exploración de datos, tratamiento de valores nulos, visualización, intervalo de confianza y prueba de hipótesis.

## Competencias demostradas

- Creación y manipulación de datos con pandas y NumPy.
- Identificación y tratamiento de valores nulos.
- Estadística descriptiva.
- Evaluación de distribución y normalidad.
- Intervalo de confianza del 95%.
- Prueba t de una muestra.
- Interpretación práctica de resultados.

## Ejecución

```bash
python desafio_inferencia_estadistica.py
```

El script genera un histograma de los puntajes de satisfacción en la misma carpeta del proyecto.
