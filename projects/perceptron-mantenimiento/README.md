# Perceptrón para mantenimiento preventivo

## Objetivo

Construir un perceptrón simple que clasifique el estado de un vehículo a partir de dos variables normalizadas: vibración y temperatura del motor.

## Salida

- `0`: operación normal.
- `1`: alerta de mantenimiento preventivo.

## Competencias demostradas

- Implementación manual de un perceptrón.
- Inicialización de pesos y sesgo.
- Función de activación binaria.
- Actualización de parámetros durante el entrenamiento.
- Evaluación de convergencia.

## Ejecución

```bash
python perceptron_alerta_mantenimiento.py
```
