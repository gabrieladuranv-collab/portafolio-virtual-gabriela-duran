# Aprendizaje no supervisado

## Objetivo

Explorar técnicas de aprendizaje no supervisado mediante segmentación con K-means y reducción de dimensionalidad con PCA.

## Elementos principales

- Preprocesamiento de variables numéricas y categóricas.
- Estandarización y codificación One-Hot.
- Comparación de distintos valores de `k` mediante Silhouette Score.
- Ajuste final de K-means.
- Visualización bidimensional con PCA.
- Interpretación de perfiles por cluster.

## Ejecución

```bash
python desafio_exploracion_unsupervised.py
```
