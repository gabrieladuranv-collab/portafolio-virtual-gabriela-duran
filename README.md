## Propósito del portafolio

Este repositorio reúne trabajos desarrollados durante mi proceso de formación y presenta una selección organizada de proyectos que muestran habilidades en estadística, análisis de datos, machine learning y redes neuronales.

La organización busca que cada trabajo pueda revisarse de manera independiente y que la documentación permita comprender el problema abordado, las herramientas utilizadas y las principales decisiones técnicas.

## Repositorio seleccionado

Elegí **GitHub** porque permite mantener control de versiones, organizar proyectos en carpetas, documentar cada trabajo mediante Markdown, compartir un enlace único y facilitar la revisión directa del código. Además, permite complementar el repositorio con una versión web estática.

## Buenas prácticas consideradas

- Una carpeta por proyecto.
- README general y documentación específica por trabajo.
- Nombres de archivos descriptivos y consistentes.
- Dependencias declaradas en `requirements.txt`.
- Uso de `.gitignore` para archivos temporales y configuraciones locales.
- Semillas aleatorias cuando corresponde para favorecer reproducibilidad.
- Separación entre código, documentación y resultados.
- Registro explícito de dependencias o datos faltantes.
- No presentar material de apoyo docente como trabajo propio.
