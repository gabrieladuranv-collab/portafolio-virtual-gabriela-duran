# Planificación del portafolio virtual

## 1. Repositorio seleccionado

El repositorio escogido es **GitHub**. La elección se basa en su uso extendido en desarrollo y análisis de datos, su capacidad de mantener control de versiones y la posibilidad de organizar proyectos mediante carpetas y archivos README. También permite compartir el trabajo mediante un enlace único y complementar el repositorio con una versión web estática.

## 2. Referente de portafolio

Se revisó el portafolio de Brittany Chiang como referencia de organización visual y presentación de proyectos.

Enlace principal: https://brittanychiang.com/

### Características valoradas

1. La jerarquía visual permite distinguir rápidamente presentación, experiencia y proyectos.
2. Cada proyecto incluye contexto y tecnologías utilizadas, facilitando la comprensión del trabajo realizado.

### Aspectos perfectibles para mi propio portafolio

1. Prefiero una presentación con menor dependencia de animaciones o efectos visuales.
2. Quiero dar mayor visibilidad a las decisiones metodológicas, limitaciones y aprendizajes de cada proyecto.

## 3. Trabajo seleccionado como muestra principal

Se selecciona **Inferencia estadística** como trabajo principal porque reúne varias competencias relevantes: creación y exploración de datos, tratamiento de valores nulos, estadística descriptiva, visualización, cálculo de intervalo de confianza y prueba de hipótesis.

Además, permite mostrar una secuencia completa de análisis, desde la preparación de datos hasta la interpretación de resultados.

## 5. Buenas prácticas consideradas

- Mantener una carpeta independiente por proyecto.
- Incorporar un README general y documentación específica por cada trabajo.
- Usar nombres de archivos claros y consistentes.
- Declarar dependencias en un archivo `requirements.txt`.
- Usar `.gitignore` para archivos locales, temporales o sensibles.
- Favorecer reproducibilidad mediante semillas aleatorias cuando corresponde.
- Separar código, documentación y resultados.
- Documentar limitaciones y dependencias externas.
- No presentar material de apoyo docente como si fuera trabajo propio.
